# 🦅 نظام النسر لاستخراج الفواتير | Al-Nasr Invoice Extraction System

نظام استخراج فواتير ثنائي اللغة متطور مع لوحة تحكم ذكية وإحصائيات شاملة.

**المطور:** المهندس عبد السلام فيصل العمري | Engineer Abdul Salam Faisal Al-Omari

---

## ✨ المميزات الرئيسية

### 📊 لوحة التحكم الذكية
- **4 بطاقات إحصائية**: رقم الفاتورة الحالية، إجمالي الطلبات، طلبات اليوم، رقم الدورة
- **شارت تقدم الدورة**: شريط تقدم مرئي يوضح موضع الطلب الحالي ضمن الدورة (كل 50 طلب)
- **مخطط دائري**: نسبة إنجاز الدورة الحالية بشكل بصري جذاب
- **إحصائيات تلقائية**: تحديث فوري للإحصائيات بعد كل عملية استخراج

### 🔄 نظام الدورات الذكي
- كل دورة تحتوي على **50 طلباً**
- عند الوصول إلى الطلب رقم 50، يبدأ العد من جديد تلقائياً
- عرض واضح للطلب الحالي، المتبقي في الدورة، ورقم الدورة
- تنبيه عند اكتمال الدورة وبداية دورة جديدة

### 📤 عملية الاستخراج
- **وضع واحد مبسط**: بدون خيارات معقدة، استخراج سريع ومباشر
- **شريط تقدم تفاعلي**: 3 خطوات واضحة (قراءة الملف → تحليل البيانات → تنسيق النتائج)
- **استخراج دقيق**: باستخدام مكتبة PyMuPDF القوية
- **تحديد منطقة العميل**: تقنية متقدمة لاستخراج بيانات العميل بدقة من مكانها في الصفحة

### 📋 ميزات إضافية
- زر **نسخ** فعلي للحافظة باستخدام JavaScript
- زر **تحميل** كملف نصي
- زر **فتح في واتساب** مباشرة
- تصميم عصري يدعم الاتجاه من اليمين لليسار (RTL)
- واجهة متجاوبة تعمل على جميع الأجهزة

## 🚀 التشغيل المحلي

### 1. إنشاء بيئة افتراضية
```bash
python -m venv .venv
```

**ويندوز:**
```bash
.venv\Scripts\activate
```

**ماك / لينكس:**
```bash
source .venv/bin/activate
```

### 2. تثبيت الاعتمادات
```bash
pip install -r requirements.txt
```

### 3. تشغيل التطبيق
```bash
streamlit run app.py
```

سيفتح المتصفح تلقائياً على: `http://localhost:8501`

## 📖 طريقة الاستخدام

1. **اختر ملف PDF**: اضغط على زر رفع الملف واختر فاتورة PDF
2. **تحقق من رقم الفاتورة**: في الشريط الجانبي الأيسر
3. **اضغط استخراج البيانات**: شاهد شريط التقدم خلال العملية
4. **استخدم النتائج**: انسخ، حمل، أو شارك عبر واتساب
5. **تابع الإحصائيات**: شاهد تحديث لوحة التحكم فوراً
