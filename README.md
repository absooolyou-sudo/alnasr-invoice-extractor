# Absoool Env System — Invoice Extractor (Web Version)
نظام استخراج فواتير ثنائي اللغة لمتجر النُّر للأحذية، **نسخة الويب** تعمل عبر المتصفح مباشرة باستخدام Streamlit.

## ✨ الميزات
- واجهة ويب عربية/إنجليزية بتصميم عصري ودعم كامل لاتجاه RTL
- استخراج بيانات العميل من ملفات PDF (الاسم، الحي، رقم الجوال، رقم الطلب)
- معالجة ذكية للنص العربي وعكس السطور المعكوسة
- دعم الأرقام العربية والفارسية وتحويلها تلقائياً
- تصحيح أخطاء شائعة في أسماء الأحياء (الرنجس → النرجس وغيرها)
- التحقق من صحة البيانات وإظهار التنبيهات الواضحة
- حفظ رقم الفاتورة التالي تلقائياً
- خيارات: تحميل كملف نصي، نسخ النتيجة، فتح في واتساب
- عرض النص الخام المستخرج لأغراض التصحيح

## 🚀 التشغيل المحلي

### 1. إنشاء بيئة افتراضية
```bash
python -m venv .venv
```

في ويندوز:
```bash
.venv\Scripts\activate
```

في ماك أو لينكس:
```bash
source .venv/bin/activate
```

### 2. تثبيت الاعتمادات
```bash
pip install -r requirements.txt
```

### 3. تشغيل التطبيق
```bash
streamlit run app.py
```

سيفتح المتصفح تلقائياً على العنوان: `http://localhost:8501`

## 📖 طريقة الاستخدام
1. اختر ملف PDF للفاتورة من جهازك
2. تحقق من رقم الفاتورة الحالية في الشريط الجانبي
3. اضغط على زر **"استخراج البيانات"**
4. راجع النتيجة والتنبيهات إن وجدت
5. انسخ النتيجة أو حملها كملف أو افتحها في واتساب

## 📝 ملاحظات
- يتطلب Python 3.10 أو أحدث
- النظام يعمل بشكل أفضل مع ملفات PDF النصية
- للملفات الممسوحة ضوئياً (صور)، ستحتاج لإضافة تقنية OCR عربي
- جميع البيانات تتم معالجتها محلياً ولا يتم إرسالها لأي خادم خارجي

## 🔧 المعالجات المتاحة
- `normalize_digits()`: تحويل الأرقام العربية والفارسية للإنجليزية
- `reverse_pdf_line()`: عكس السطور العربية فقط مع الحفاظ على الإنجليزية
- `normalize_neighborhood()`: تصحيح أخطاء أسماء الأحياء الشائعة
- `extract_customer_region()`: استخراج بيانات العميل من منطقة محددة في الصفحة
- `validate_data()`: التحقق من صحة البيانات المستخرجة
